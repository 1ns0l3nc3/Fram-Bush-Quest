je mange 


Action-RPG 2D en pixel art, ambiance MMO, fait avec Godot 4.

- Architecture et structure du projet : [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)


1. Installer Godot 4 (version standard, pas .NET).
2. Dans Godot, `Nouveau projet`, choisir ce dossier (Godot prévient qu'il n'est pas vide, c'est normal), moteur de rendu `Compatibilité` ou `Mobile` pour rester léger.
3. Appliquer les réglages de la section 1 du document d'architecture.
